
## 🚀 Getting Started

1. **Clone or download** all files keeping the folder structure.
2. **Open any HTML file** directly in your browser (Chrome / Firefox / Edge).  
   *For best experience, use **Live Server** extension (VS Code) or run `npx serve .` to avoid CORS quirks.*
3. **All data** is stored in your browser's localStorage. You can reset by clearing application data.

## 🎯 Recommendation Logic (Mock)
- **Continue Learning** – enrolled but not completed.
- **Recommended for You** – based on most completed category.
- **Because You Completed X** – other courses from last completed course’s category.
- **Popular Courses** – sorted by highest completion count.
- **Beginner Friendly** – difficulty = Beginner.

## 🧩 Customisation

- Styles use TailwindCDN – modify classes directly.
